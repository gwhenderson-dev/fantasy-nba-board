# NBA Fantasy Basketball Points League Database

A fantasy basketball draft model for H2H points leagues, published as a single
self-contained page: **https://gwhenderson-dev.github.io/fantasy-nba-board/**

Set your league's scoring, roster size and playoff weeks, and the board and 24
seasons of walk-forward backtests re-rank in your browser. Tabs: Board, Draft
(live draft tracker), Method (how the projections are built), Proof (backtests)
and Sources.

This repo holds only the built page (`index.html`). The model that generates
it lives in a separate project.
